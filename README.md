# RT METAL Production Website

生产级 Next.js 15 + TailwindCSS B2B 独立站模板，适合部署到 GitHub + Vercel。

## 功能
- RT METAL 首页
- 9 大产品分类
- 产品列表、分类页、产品详情页
- OEM & ODM、Factory、About、Contact、Blog
- SEO metadata、robots、sitemap、JSON-LD
- WhatsApp 浮动按钮
- 询盘 API，可接 Resend 邮件
- Cloudflare R2 图片公共地址预留

## 部署
```bash
npm install
npm run dev
npm run build
```

把项目上传到 GitHub，Vercel 导入仓库即可。环境变量参考 `.env.example`。
